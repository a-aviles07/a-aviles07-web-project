# a-aviles07-web-project/final

Final Project -
    This final project is for a client looking to gain business by helping businesses become more Eco-Friendly and environmentally responsible using products and services that they provide. It includes an easy navigation bar that let's the user switch from pages depending on what they are looking for. The Navigation bar includes an "About" page that gives the user a look into who the company is and who works there.It gives a "Products" page that provides information on the products that they have. It has a "Blog" page that provides different links to articles to help the user read more into becoming eco-friendly. And lastly, it has a "Contact Us" page that includes a form for the user to input their information and a message for the business to contact them back. It includes pictures relative to the client's wants. I created the webpage to be visible with light earthy green tones that aren't too strong and not to light as well. I included hover options for different sections so the webuser would be able to see what section they are looking at and read important information.

    The way I started this project is by doing it one section at a time. For example, doing the index.html page, and then doing the css styles page, then the javascript page and so forth. This made it easier when coming to styling the webpage a specific way and not having to figure out what needed to be decorative, what needed changes, and what needed to still be added at the end of everything.
    The technologies used to set up and run the project are VSCode and Github. I also used pixaby to locate free stock pictures for use. VSCode was used primarily to write the full code and github was used for the url to become live.
    This webpage is also located in my main index.html page with all the other projects that have been completed this semester.
